🛠️ Technical Architecture Specification

  • SARIMAX Model: Captures non-stationary linear temporal dynamics and exogenous weather variable influences (Irradiance, Temp, Humidity, Wind).
  • LSTM Neural Network: Trained strictly on SARIMAX residuals (e_t = y_t - y_SARIMAX) to model nonlinear high-frequency atmospheric corrections.
  • Hybrid Combination: Final Prediction y_final(t) = y_SARIMAX(t) + e_LSTM(t).
  • Open-Meteo Integration: Live hourly weather telemetry direct API synchronization.
  • BESS Simulation: Discrete hourly dispatch accounting for charge/discharge efficiency, maximum C-rate, and state-of-charge safety bounds.
